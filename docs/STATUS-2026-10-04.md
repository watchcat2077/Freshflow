## 1. What the project is, in plain words

A supermarket throws away food that reaches its expiry date unsold. The decision that
prevents that waste is a **markdown**: drop the price early enough that the stock clears,
but never so far that the sale loses money.

FreshFlow watches sales as they happen, works out which batches will not sell out before
they expire, and asks an LLM agent to propose a markdown for those batches. A second agent
writes the store owner's end-of-day briefing. The agents only **propose** or **summarise**.
Whether a markdown is allowed is decided by a deterministic rule, the margin floor, inside the
pricing service's domain layer, and it decides the same way for a person and for the agent.

| Context | Service | Port | Domain pattern |
|---|---|---|---|
| Inventory & Batch | `inventory-service` | 8081 | Domain Model |
| Sales | `sales-service` | 8082 | Transaction Script |
| Pricing & Markdown | `pricing-service` | 8083 | Domain Model |
| Insight | `insight-service` | 8084 | CQRS read side with a small domain package (ADR 0006) |

Plus `contracts` (the Published Language, event records only) and `pos-simulator` (a JDK-only
command-line client that drives the demonstration).

### Known limitations, stated in the report

G-3 trading hours are configuration; G-4 a SKU that stops selling is not re-assessed; G-6 the
wire-format contract test exists now; G-7 save-then-publish without an outbox (also the
position of the coordinator's reference code). A pricing-service restart re-announces its
seeded rules and displaces an attached markdown in sales-service until the markdown is
republished (documented in README troubleshooting).

### Things never to do

- Add a dependency outside spec-01 §1.1 without coordinator approval.
- Weaken, edit or delete a test, especially the `HandlerMethod` guards, the domain import
  guards and `AntiCorruptionLayerGuardTest`.
- Put a business invariant in a controller or in a prompt.
- Let sales-service call pricing-service synchronously.
- Put JPA annotations on domain classes in inventory-service or pricing-service.
- Introduce aggregate roots or aggregate-oriented repositories in sales-service.
- Run Maven from Git Bash: the repository path contains an ampersand that breaks `cmd.exe`.
  Use PowerShell or IntelliJ.
- Skip the `docs/ai-log/` entry, or leave work uncommitted at the end of a session.
